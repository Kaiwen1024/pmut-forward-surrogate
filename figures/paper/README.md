# Manuscript Figures

This directory contains the manuscript data-display figures associated with
the current artifact release. The copied PDF exports are byte-identical to the
files included by `manuscript/paper_sensors2026/main.tex` when the artifact
package was prepared.

| Manuscript figure | Repository export | What it shows |
|---|---|---|
| Fig. 2 | `fig2_training_curves/export/fig2_training_curves.*` | Training loss, validation loss, and validation RMSE curves. |
| Fig. 3 | `fig3_test_prediction/export/fig3_test_prediction.*` | Held-out field prediction examples at low, medium, and high active-element counts. |
| Fig. 4 | `fig4_application_metric_consistency/export/fig4_application_metric_consistency.*` | Consistency of application-level physical metrics. |
| Fig. 5 | `fig5_field_error_breakdown/export/fig5_field_error_breakdown.*` | Test-set field-error breakdown by frequency and active-element interval. |

Each figure folder has the same structure:

```text
export/    PDF, PNG, and SVG exports used for review and inspection
source/    plotting script used to generate the figure
data/      compact derived data or metadata used by the plotting script
```

The exported files are the primary manuscript-figure record. The source scripts
are included for auditability, but some scripts need intermediate prediction
arrays generated by `bash scripts/evaluate_fullrange_test.sh`. In particular,
Fig. 3 and Fig. 5 use `results/fullrange_10k_retrain/eval_test/y_test_*.npy`
and `test_global_indices.npy`; these large arrays are ignored by default and
can be regenerated locally from the released checkpoint and split cache.

If a reviewer reruns evaluation or retraining and then reruns these plotting
scripts, the exports in this directory will be regenerated from the reviewer's
local outputs. This is expected: the committed exports are the manuscript
figures associated with this artifact release, while the scripts are an audit
path for reproducing or regenerating them. Re-evaluating the released
checkpoint should only introduce small floating-point or environment-dependent
differences. Full retraining can lead to larger differences because the
optimization trajectory is rerun.

Fig. 5 also uses the raw `.mat` dataset only when recomputing frequency
metadata and active-element counts from scratch. The raw `.mat` files are not
part of this GitHub artifact package; the derived tables already stored in
`data/` are sufficient to inspect the released manuscript figure.

Run plotting scripts from the repository root, for example:

```bash
export PYTHONPATH="$PWD/src:$PYTHONPATH"
python figures/paper/fig2_training_curves/source/draw_fig2_training_curves.py --singlecol-only
python figures/paper/fig4_application_metric_consistency/source/draw_fig4_application_metric_consistency.py
```

The lightweight repository-inspection figures in `figures/artifact/` are
separate from these manuscript figures.
